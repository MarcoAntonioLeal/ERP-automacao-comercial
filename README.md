# 📖 Sobre o Projeto

O Say System surgiu da necessidade de oferecer uma solução de automação comercial simples, leve e acessível para pequenos empreendedores.

Muitos profissionais trabalham em suas próprias residências, realizam vendas diariamente e conseguem emitir notas fiscais por meios alternativos, porém não possuem um sistema eficiente para controlar:

- Estoque;
- Clientes;
- Fornecedores;
- Entradas de mercadorias;
- Pedidos;
- Vendas;
- Fluxo de caixa.

O objetivo do projeto é fornecer uma ferramenta intuitiva, rápida e de fácil utilização, sem abrir mão da qualidade e organização dos dados.

---

# 🎯 Objetivos

- Facilitar o controle operacional de pequenos negócios;
- Centralizar informações em uma única aplicação;
- Reduzir processos manuais;
- Melhorar o controle de estoque;
- Acompanhar vendas e movimentações;
- Oferecer uma interface simples e intuitiva;

# 🏗️ Arquitetura

O sistema será desenvolvido utilizando a arquitetura MVC (Model-View-Controller).

## Model

Responsável pelo acesso e manipulação dos dados.

## View

Responsável pela interface gráfica apresentada ao usuário.

## Controller

Responsável por intermediar as regras de negócio entre as Views e os Models.

---

# 🖥️ Plataforma

O sistema será distribuído como aplicação desktop utilizando Electron.

Dessa forma o usuário poderá instalar e utilizar o ERP diretamente em seu computador, sem necessidade de hospedagem ou acesso constante à internet.

# 🛣️ Roadmap

O projeto está sendo desenvolvido inicialmente pelo front-end, área na qual possuo maior experiência. Após a conclusão das interfaces e fluxos de navegação, serão implementados o back-end utilizando Node.js, Express e arquitetura MVC, seguido da integração com SQLite e posteriormente da adaptação para aplicação desktop através do Electron.
